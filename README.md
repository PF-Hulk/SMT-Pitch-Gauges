### Purpose:
- Quickly determine and verify the correct mechanical feeder pitch for
  pick-and-place machines, reducing setup errors and operator learning curves.

### Contents:
- 3D model files containing gauge tools of varying pitch sizes 
  - e.g., 4mm, 8mm, 12mm, etc.
- 3D model files containing box file to hold gauges with a lid

### Usage & Benefits:
- Operators place the gauge on the reel to confirm tape pitch alignment before
  loading components.
- Minimizes misfeeds, pick errors, and subsequent rework by ensuring accurate
  feeder setups.
- Speeds up new operator training, providing a clear visual/tactile reference.
- Align same position corners of adjacent embossed pockets to identify applicable pitch

### Implementation Tips:
1. Integrate pitch checks into the standard feeder setup process to ensure
   consistent results.
2. Inspect gauges periodically for wear or damage to maintain measurement
   accuracy over time.
3. Use ESD safe filament when 3D printing to reduce chances of damaging parts.
4. I recommended Protopasta's Static Dissipative PLA (PLA1170-ESD) filament. The technical datasheet shows a tested max 10^8 Ω using a Desco 19786. I personally have validated this and is compliant with the strict ANSI/ESD S20.20-2021 standard.
